# LIMITATIONS —— Terminal-Style-UI-VSCode 已知局限

> 2026-09-25 Claude Code 整理。

## 1. 继承渲染库的局限

见 terminal-style-ui-web/LIMITATIONS.md：重新打包需定制版 pi-tui、字体平台绑定（Monaco / PingFang）、超长表格的 DOM 体积、双线制表符的转角近似画法。

## 2. Webview 是 Chromium，不是 Safari

渲染库的观感按 Safari（WebKit / CoreText）调校；VSCode Webview 是 Chromium。实机截图观感一致，但未与 Safari 逐像素比对。

## 3. 联动是块级精度

源码映射以顶层块（段落 / 标题 / 表格 / 代码块 / 列表…）为单位，块内按行数线性插值——长段落、长列表内部可能差一两行（内置预览同为块级）。编辑器开着粘性滚动（Sticky Scroll）时，编辑器 → 预览以被悬浮标题盖住的那一行对齐，会比肉眼所见的顶行早 0～5 行。

## 4. 整行滚动的边界

- 底边对齐：视口高度一般不是行高的整数倍，最上面一行可能被截（同终端）；页顶是例外，从页顶往下的第一步移动半行到一行半。
- 横向滚动（固定列数且面板更窄时）交给浏览器，不按列吸附；不显示滚动条，横向只能用触控板 / Shift+滚轮。

## 4b. 选区

- 选区块内的表格线仍是原来的颜色（dark 下浅灰压在浅蓝上，对比偏弱）；iTerm 会把选中的制表符也染黑。
- 双击预览会跳到源码（同内置预览），所以双击选词后焦点会切到编辑器；拖选、三击不受影响。

## 4c. 导出

- PDF 依赖本机 Chrome / Edge / Chromium / Brave；字体用本机的 Monaco / PingFang（嵌入 PDF），换机器打开 PDF 不受影响，但在没有这两款字体的机器上重新导出会回退字体。
- 页宽按 Monaco 字宽估算；导出为一整张长页（屏幕阅读无分页白缝），直接拿去纸张打印时需在打印对话框里缩放 / 分页。

## 4d. ☀ / ☾ 按钮

标题栏按钮只在预览获得焦点时显示（VSCode 的 `activeWebviewPanelId` 跟随焦点）；命令面板里随时可用。

## 5. 与 TUI 一致而「不做」的

链接只显示文字、不可点击；图片只显示替代文字；独立 `---` 分割线不渲染。

## 6. 预览面板的行为

- 只跟随语言模式为 Markdown 的编辑器；未登记后缀的文件需显式打开预览，或先「将此后缀识别为 Markdown」。
- 重启 VSCode 后预览面板不恢复（自定义编辑器会恢复）。

## 7. 安装方式

.vsix 安装后插件是一份拷贝，库路径退回固定默认值——移动渲染库目录或换机器需设置 `terminalStyleUi.libraryPath`。插件自身代码改动需重新打包安装；渲染库改动只需重载窗口。
